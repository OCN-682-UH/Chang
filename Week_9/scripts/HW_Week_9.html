Homework

Working with intertidal data. Your goal is to make a plot where at least one axis is a factor in a meaningful order.

  • Data files in the data/ folder: intertidal.csv and intertidal_latitude.csv (plus a data dictionary)
  • You may need to use string-cleaning skills (check out the {janitor} package) to tidy column names
  • If you visualize by tide height, it must go Low → Mid → High on the plot
  • If you visualize by site, it must go in order of latiude (N->S or S->N)

Data visualization

Show code 
ggplot(intertidallat_low, aes(x=Site, y=Algae, color=Site))+
  geom_boxplot()+
  geom_jitter()+ # good visualization of all the data points
  labs(title="Algae at Low Tide", x="Location", y="Algae")+ 
  theme_minimal()+
  theme(axis.text.x = element_blank()) # get rid of all crazy x labels

Applying Factor

Show code 
algae_low<- ggplot(intertidallat_low, aes(x=fct_reorder(Site, Latitude, .desc=TRUE), y=Algae, color=Site))+ # fct_reorder puts the sites in order of latitude, .desc = TRUE I found online; puts them in descending order, resulting in N->S
  geom_boxplot()+
  geom_jitter()+
  labs(title="Algal Cover at Low Tide", x="Latitude (North to South)", y="Algae")+ 
  theme_minimal()+
  theme(axis.text.x = element_blank(),# get rid of all crazy x labels
        legend.position="none") # also get rid of the busy legend

ggplotly(algae_low) # make it a plotly so you can still see coordinates and site name
